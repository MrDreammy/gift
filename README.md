# Гра на мільйон — подарунок до річниці

Вікторина у форматі телегри: 20 запитань, шкала призів,
незгоряні суми, підказки «50 на 50», «Дзвінок другу» й «Допомога залу».
Чистий HTML/CSS/JS — без збирання, без сервера, без залежностей.

## Структура

```
.gitlab-ci.yml      ← публікація на GitLab Pages
public/
  index.html        ← сторінка гри
  style.css         ← оформлення
  game.js           ← рушій (чіпати не потрібно)
  questions.js      ← ЗАПИТАННЯ, призи й тексти — редагуй тільки його
  img/              ← сюди можна покласти фото для запитань
```

## Як змінити запитання

Відкрий `public/questions.js` — там докладні коментарі, а місця для
підлаштування під вашу історію позначені ✏️.
Перевірити локально: просто відкрий `public/index.html` подвійним кліком у браузері.

## Як опублікувати на GitLab Pages

1. Створи новий проєкт на gitlab.com (New project → Create blank project).
2. Завантаж туди файли (через `git push` або Web IDE / Upload file),
   зберігши структуру: `.gitlab-ci.yml` у корені, решта — у `public/`.
3. Після коміту в основну гілку запуститься пайплайн (Build → Pipelines).
   Дочекайся зеленої галочки біля задачі `pages`.
4. Посилання на гру з’явиться в **Deploy → Pages**.

Через git:

```bash
git init
git add .
git commit -m "Гра-подарунок"
git branch -M main
git remote add origin https://gitlab.com/<логін>/<проєкт>.git
git push -u origin main
```

### Якщо посилання не відкривається в отримувачки

Для приватного проєкту сайт за замовчуванням теж може бути приватним.
Зайди в **Settings → General → Visibility, project features, permissions**
і в пункті **Pages** вибери **Everyone** (або зроби проєкт публічним).

> Зауваж: відповіді лежать у `questions.js`, і допитлива людина може
> підгледіти їх через інструменти розробника. Для подарунка це зазвичай не проблема.
